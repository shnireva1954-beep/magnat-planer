# Магнат

Личное веб-приложение: жизнь как игра-тайкун. Привычки, задачи, финансы,
тело и награды в одном месте — галочки дают монеты, монеты растят уровень
от Новичка до Магната.

Живёт по адресу https://magnat-planer.ru (GitHub Pages из ветки `main`).

## Как устроено

Одна страница без сборки и без зависимостей:

| Файл | Что это |
|---|---|
| `index.html` | всё приложение — разметка, стили и логика внутри |
| `sw.js` | service worker: приложение открывается без интернета |
| `manifest.json`, `icon*.png` | установка на главный экран как обычного приложения |
| `app.html` | заглушка-редирект со старого адреса на корень |
| `tests/` | автоматический прогон приложения в браузере |

Данные хранятся только в браузере (`localStorage`, ключ `magnat_app_v2`),
никуда не отправляются: ни аналитики, ни серверов, ни чужих скриптов на
странице. На экране «Обзор» есть кнопки «Скачать копию данных» и
«Восстановить из копии» — это страховка при смене телефона.

## Проверка перед публикацией

```bash
npm i playwright-core      # один раз
node tests/run.js
```

Подробности — в `tests/README.md`.

## Что проверено

Приложение прогоняется в настоящем браузере по четырём наборам проверок.
Покрыто:

- **Первый запуск** — чистый лист и режим примера, все шесть экранов.
- **Реальные действия** — отметка привычки чипом и клеткой календаря,
  задача (создать, выполнить, изменить, удалить), доход и расход, вес
  с запятой, покупка награды, правка и удаление наград.
- **Порченые данные** — пять видов мусора в хранилище: отсутствующие
  поля, чужие типы, посторонний JSON, обрывок строки, ссылки на
  несуществующие привычки. Приложение чинит данные и продолжает работать.
- **Данные старого формата** переезжают без потери покупок и потраченного.
- **Копия данных** выгружается файлом и загружается обратно на «новом
  телефоне» — состояние совпадает один в один.
- **Обновление версии** доезжает до установленного приложения само.
- **Границы** — переход через полночь, часовые пояса от Кирибати до
  Мидуэя, максимальный уровень, два года истории, тридцать привычек,
  двести операций, очень длинные названия, пустые списки.
- **Экран и палец** — ширины 280 / 320 / 390 / 1280, альбомная
  ориентация, увеличенный шрифт, низкий экран с открытой клавиатурой,
  размеры кнопок, обход всех кнопок на всех экранах без единой ошибки.
- **Устойчивость** — переполнение хранилища, две вкладки одновременно,
  быстрые повторные касания, триста перерисовок подряд без утечки.

## Чего это не гарантирует

Честно: полного отсутствия ошибок не гарантирует ни один набор тестов, и
этот тоже. Он проверяет то, что в него заложено, в Chromium на Linux.
Вне охвата остаются:

- настоящий Safari на iPhone — своё поведение клавиатуры, безопасной
  зоны и эмодзи (безопасная зона в тестах только имитируется);
- установка на главный экран и режим standalone;
- плохая связь: офлайн проверяется, медленная сеть — нет.

Поэтому после заметных правок стоит открыть приложение на телефоне и
пройтись по экранам руками.

## Если что-то сломалось

1. **Данные целы почти всегда.** Они лежат в браузере отдельно от кода.
   Даже если экран не построился, приложение показывает экран спасения
   с кнопкой «Скачать копию» — сначала сохрани копию.
2. **Копию можно вернуть** кнопкой «Восстановить из копии» на «Обзоре».
3. **Откатить версию сайта:** `git log --oneline`, найти рабочий коммит,
   `git checkout main && git revert <коммит> && git push`. Сайт
   пересоберётся за пару минут, приложение подтянет старую версию само.
4. **Совсем начать заново:** внизу «Обзора» есть «сбросить всё и начать
   с чистого листа». Перед этим — скачать копию.
