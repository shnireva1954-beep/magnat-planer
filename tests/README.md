# Проверки «Магната»

Автоматический прогон приложения в настоящем браузере. Нужен, чтобы после
любой правки `app.html` (приложение) или `index.html` (главная) за пару минут
убедиться, что ничего не сломалось.

## Как запустить

```bash
npm i playwright-core      # единственная зависимость, ставится один раз
node tests/run.js
```

В конце будет либо `ВСЁ ЧИСТО — приложение можно публиковать`, либо список
файлов с проблемами. Если Chromium лежит в необычном месте, путь можно
задать явно: `CHROME=/путь/к/chrome node tests/run.js`.

`node_modules` и `package*.json` в репозиторий **не коммитим**.

## Чего эти проверки НЕ дают

Прогон идёт в Chromium на Linux. Он не заменяет:

- **настоящий Safari на iPhone** — там свои особенности с клавиатурой,
  безопасной зоной и эмодзи. Безопасную зону тесты умеют только имитировать;
- **установку на главный экран** — режим standalone проверяется вручную;
- **поведение при плохой сети** — офлайн проверяется, деградация связи нет.

Поэтому после серьёзных правок стоит один раз открыть приложение на самом
телефоне и пройти по экранам руками.
