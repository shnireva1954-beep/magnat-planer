# Проверки «Магната»

Автоматический прогон приложения в настоящем браузере. Нужен, чтобы после
любой правки `index.html` за пару минут убедиться, что ничего не сломалось.

## Как запустить

```bash
npm i playwright-core      # единственная зависимость, ставится один раз
node tests/run.js
```

В конце будет либо `ВСЁ ЧИСТО — приложение можно публиковать`, либо список
файлов с проблемами. Если Chromium лежит в необычном месте, путь можно
задать явно: `CHROME=/путь/к/chrome node tests/run.js`.

`node_modules` и `package*.json` в репозиторий **не коммитим**.

## Что внутри

| Файл | Что проверяет | Ворота |
|---|---|---|
| `01-scenarios.js` | Онбординг с чистого листа и с примером, все шесть экранов, реальные действия (привычка чипом и клеткой календаря, задача, доход и расход, вес с запятой, покупка награды), пять вариантов битых данных в хранилище, переход через полночь, ширины 320 / 390 / 1280, автоматические нормы калорий и воды, монеты без ценника, снятие эмодзи, правка и удаление наград, перенос данных старого формата | да |
| `02-edge.js` | Края: удалённые награды не воскресают, серия с одной привычкой, инсайт молчит на малых данных, форма на низком экране, размеры целей для пальца, удаление без подтверждения, длинные названия, картинка «Поделиться империей», два года истории, круг экспорт→импорт, максимальный уровень | нет |
| `03-stress.js` | Нагрузка и необычные условия: альбомная ориентация, увеличенный шрифт, быстрые повторные касания, переполнение хранилища, отказ от покупки, тридцать привычек и двести операций, значения вне разумных границ | нет |
| `04-final.js` | Целостность: новая версия доезжает через service worker, копия данных выгружается и загружается настоящим файлом, обход всех кнопок на всех экранах, часовые пояса от Кирибати до Мидуэя, режим «меньше движения», две вкладки одновременно, триста перерисовок подряд | да |
| `06-server.js` | Свой сервер (`server/`): `Caddyfile` проходит `caddy validate`, выкладка вырезает служебное и не выкладывает битый коммит, пять версий и откат, сломанный `Caddyfile` не применяется; настоящий Caddy отдаёт заголовки безопасности, прячет служебное, ведёт `www` на главный адрес; и весь `01-scenarios` ещё раз — уже через этот Caddy, под его CSP. Замок «не тот сервер» и снятие старой пересылки VPN — последнее на настоящем iptables в изолированных сетях (`relay-netns.sh`, нужен root; без него — видимый пропуск). Caddy скачивается сам в `node_modules/.cache` | да |

«Ворота» — файлы, падение которых означает «публиковать нельзя». Остальные
два печатают наблюдения: их читают глазами, но одиночный `✗` в них тоже
останавливает `run.js`. И само падение набора (ненулевой код возврата)
тоже: до 29.09.2026 упавший с ошибкой синтаксиса `02-edge.js` проходил
как «ВСЁ ЧИСТО».

Первый запуск с чистого листа идёт через окно выбора привычек — в тестах
это общий шаг `startClean(p)` из `lib.js`.

Снимки экранов, если тест их делает, ложатся в `tests/__snapshots` — эта
папка в репозиторий не коммитится.

## Чего эти проверки НЕ дают

Прогон идёт в Chromium на Linux. Он не заменяет:

- **настоящий Safari на iPhone** — там свои особенности с клавиатурой,
  безопасной зоной и эмодзи. Безопасную зону тесты умеют только имитировать;
- **установку на главный экран** — режим standalone проверяется вручную;
- **поведение при плохой сети** — офлайн проверяется, деградация связи нет.

Поэтому после серьёзных правок стоит один раз открыть приложение на самом
телефоне и пройти по экранам руками.
